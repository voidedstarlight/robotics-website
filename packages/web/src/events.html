SUMMER CAMPS

Summer Camps 2027

Are you a rising 6th–12th grader interested in programming, building, or designing a robot? Grizzly Robotics Summer Camps will be back next year during the months of June-July right at our home of Granite Bay High School! We’ll teach you the entire process using fun, hands-on techniques!

Registration will open in early-April, check this page later for more updates on dates and availability!


EARLY JUNE

Week 1: Building

Students learn the fundamentals of building with VEX parts and create a fully functional competition robot for the upcoming VEX season.

LATE JUNE

Week 2: Programming

Using the C++ programming language, students code controls and autonomous routines for robots to compete in a scrimmage at the end of the week.

EARLY JULY

Week 3: Computer-aided design (CAD)

A one-week introduction to the engineering design process and designing robots using Autodesk Inventor to plan changes and build iterations.
